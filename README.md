# 🎮 Games.Net

> **Games.Net — jogos indie em um só lugar!**

O **Games.Net** é um aplicativo mobile desenvolvido para reunir, organizar e apresentar **jogos independentes (indie)** da comunidade em uma única plataforma.

A proposta do projeto é facilitar a descoberta de novos títulos, permitindo que os usuários naveguem por diferentes categorias, conheçam jogos e acessem informações sobre cada obra de forma simples, visual e organizada.

---

## 📱 Sobre o projeto

O aplicativo foi desenvolvido como um projeto acadêmico por **Pedro Paulo** e **Nataly Silva**, utilizando **JavaScript** e **React Native**.

O Games.Net possui uma interface inspirada em plataformas de catálogo de jogos, com navegação por abas e páginas individuais para apresentar informações dos títulos.

### 🎯 Objetivo

O principal objetivo do Games.Net é:

- Facilitar a descoberta de jogos independentes;
- Reunir diferentes títulos em um único aplicativo;
- Organizar os jogos por categorias;
- Apresentar informações de cada jogo de maneira clara;
- Criar uma experiência simples e intuitiva para os usuários.

---

## ✨ Funcionalidades

- 🏠 **Tela inicial** com apresentação do aplicativo;
- 🎮 **Catálogo de jogos** com títulos disponíveis;
- 🗂️ **Categorias** para facilitar a navegação;
- 📖 **Página individual dos jogos**, com imagens e descrição;
- ❤️ Exibição de informações como **curtidas**;
- 👥 Exibição da quantidade de **seguidores**;
- 📱 **Navegação por abas** para acessar as principais áreas do aplicativo.

## 🧭 Estrutura de navegação

O aplicativo utiliza uma navegação por abas na parte inferior da tela, permitindo acesso rápido às principais áreas:

| Seção | Função |
|---|---|
| 🗂️ Categorias | Explorar os jogos por categorias |
| 🏠 Home | Tela inicial do aplicativo |
| 🎮 Jogos | Visualizar os títulos disponíveis |
| ℹ️ Sobre Nós | Informações sobre o projeto |
